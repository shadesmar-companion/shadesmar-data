# shadesmar-data

Stormlight Archive lore dataset for [Shadesmar Companion](https://github.com/shadesmar-companion/shadesmar-app).                                  

**Status** : Work in Progress

## Content policy

All entity descriptions are written independently, based on the Stormlight Archive books. Coppermind is referenced for fact verification only — no Coppermind text is reproduced.

# Attribution

## Primary source

All lore in this dataset is derived from the **Stormlight Archive** series by **Brandon Sanderson**, published by Tor Books and Dragonsteel Entertainment:

| Title               | Type               | Year |
| ------------------- | ------------------ | ---- |
| _The Way of Kings_  | Novel (Book 1)     | 2010 |
| _Words of Radiance_ | Novel (Book 2)     | 2014 |
| _Edgedancer_        | Novella (Book 2.5) | 2016 |
| _Oathbringer_       | Novel (Book 3)     | 2017 |
| _Dawnshard_         | Novella (Book 3.5) | 2020 |
| _Rhythm of War_     | Novel (Book 4)     | 2020 |
| _Wind and Truth_    | Novel (Book 5)     | 2024 |

All descriptions are **independently authored** by contributors to this dataset, based on direct reading of the above works. This is not a transcription, translation, or adaptation of the source text.

The [Coppermind wiki](https://coppermind.net) (licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)) is used by contributors **as a factual verification reference only** — to confirm character names, spellings, affiliations, and plot points when working from memory.

**No Coppermind text is reproduced in this dataset.** All entity descriptions are written from scratch by contributors.
